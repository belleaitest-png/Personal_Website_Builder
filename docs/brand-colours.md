# Annabelle Body — Brand Theme

## Typography

**One font across the entire site: Cormorant Garamond**

| Element              | Weight | Size (approx)  | Notes                        |
|----------------------|--------|----------------|------------------------------|
| Logo / Wordmark      | 600    | 26px           | Deep coral red `#D84535`     |
| H1 Hero heading      | 700    | clamp 44–80px  | White                        |
| H2 Section heading   | 700    | clamp 32–52px  | White                        |
| H3 Card heading      | 600    | 20–28px        | White                        |
| Body text            | 400    | 17px           | Cream `#F5F0E8`, 0.85 opacity|
| Nav links            | 500    | 15px           | Uppercase, cream             |
| Small labels / tags  | 600    | 11–12px        | Uppercase, coral accent      |
| Ticker / Quote       | 300    | clamp 1.4–2.2rem | Italic, cream               |
| Buttons              | 600    | 13–14px        | Uppercase, white on coral    |

Google Fonts import:
```
Cormorant Garamond: ital,wght@0,300;0,400;0,500;0,600;0,700;1,300;1,400
```

## Rules

- **Never** mix in a second typeface — Cormorant Garamond only.
- **Coral Red** (`#D84535`) is reserved for the logo wordmark exclusively.
- **Coral Accent** (`#E8534E`) covers all interactive elements and highlights.
- Increase font size slightly when using Cormorant Garamond at small sizes (≥15px for UI, ≥17px for body) to maintain legibility.
