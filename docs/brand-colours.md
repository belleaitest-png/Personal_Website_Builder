# Annabelle Body — Brand Colour Theme

## Primary Colours

| Name            | Hex       | Usage                                      |
|-----------------|-----------|--------------------------------------------|
| Coral Red       | `#D84535` | Logo / "Annabelle Body" wordmark           |
| Coral Accent    | `#E8534E` | Buttons, links, section labels, dividers   |

## Neutral Colours

| Name            | Hex       | Usage                                      |
|-----------------|-----------|--------------------------------------------|
| Navy            | `#060F1E` | Page background, nav backdrop              |
| Cream           | `#F5F0E8` | Body text, nav links                       |
| White           | `#FFFFFF` | Headings, button text                      |

## Typography

| Element         | Font                  | Weight |
|-----------------|-----------------------|--------|
| Logo wordmark   | Cormorant Garamond    | 400    |
| Headings (h1–h3)| Playfair Display      | 700    |
| Body / UI       | Inter                 | 300–600|
| Ticker / Quote  | Cormorant Garamond    | 300    |

## Notes
- Coral Red (`#D84535`) is reserved exclusively for the logo — warm, deep, and distinctly brand.
- Coral Accent (`#E8534E`) is used for all interactive and accent elements.
- Navy background keeps the palette feeling rich and editorial.
